# Прототипы страниц Illuminos

│ Больше, чем просто кино.            │                           │ │

## Личный кабинет и тарифы
```text
ЛИЧНЫЙ КАБИНЕТ                   ТАРИФЫ
Привет, пользователь             [Старт] [Плюс] [Премиум]
[Аккаунт] [Подписка] [Роль]      Цена и возможности каждого тарифа
Избранное                        [Выбрать тариф]
История просмотров
```

## Проверка адаптивности
На планшете карточки перестраиваются в три колонки, на телефоне — в две; навигация переносится под логотип, формы становятся одноколоночными. Контрольные ширины для проверки: 1440 px, 900 px и 390 px.
