# Проверка Illuminos

## Подготовка
- PHP 8+ и MySQL/MariaDB запущены в XAMPP.
- База `illuminos` и таблицы созданы импортом `database.sql` через phpMyAdmin.
- `config.php` содержит правильные реквизиты подключения.
- Администратор создан через `install_admin.php`; после этого установочный файл удалён.

## Функциональные проверки
1. Открыть главную страницу: видны первый экран, жанры, популярные материалы, рекомендации и промо подписки.
2. Перейти в каталог; выполнить поиск по названию, выбрать жанр и тип контента. Проверить пустой результат.
3. Открыть фильм: проверить описание, рейтинг, год, режиссёра, актёров, блок трейлера и похожие материалы.
4. Открыть сериал: проверить список сезонов и эпизодов.
5. Открыть личный кабинет без входа: сайт должен перенаправить на страницу авторизации.
6. Зарегистрировать пользователя с корректными данными; проверить вход с неверным паролем и повторной регистрацией того же email.
7. После входа добавить материал в избранное; проверить его отображение в кабинете.
8. Открыть страницу материала; проверить появление записи в истории просмотров.
9. Выбрать тариф; проверить создание подписки и роль `subscriber` в кабинете. Это тестовый сценарий без реального списания средств.
10. Войти под администратором; проверить, что роль отображается как `admin`.

## Адаптивность
Проверить отображение в браузере при ширине примерно 1440 px (компьютер), 900 px (планшет) и 390 px (телефон). Проверить отсутствие горизонтальной прокрутки, читаемость текста, сетку карточек, навигацию и формы.

## GitHub Desktop
1. Создать удалённый репозиторий GitHub и опубликовать проект.
2. Открыть репозиторий через GitHub Desktop.
3. Изменить текст в `README.md` или комментарий в `style.css`.
4. Сохранить файл и убедиться, что изменение отображается во вкладке **Changes**.
5. Сделать Commit to main и нажать Push origin.
6. Обновить страницу репозитория на GitHub и проверить, что изменение опубликовано.
