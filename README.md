# Illuminos — учебный проект онлайн-кинотеатра

Адаптивный сайт онлайн-кинотеатра на PHP, MySQL и HTML/CSS. Визуальное оформление — **дизайн №3 «Минимализм»**: светлый фон, аккуратная типографика, много свободного пространства и фиолетовые акценты.

## Что реализовано по дневнику практики
1. **Дизайн и прототипы:** палитра, wireframe-прототипы главной и типовых страниц, описание desktop/tablet/mobile состояний — папка `docs/`.
2. **HTML/CSS/PHP/SQL:** внешний `style.css`, комментарии в коде, PDO-подключение к MySQL, SQL-структура для импорта через phpMyAdmin.
3. **Главная:** новинки и популярное, жанры, рекомендации (для авторизованного пользователя подборка учитывает жанры из избранного), поиск и фильтры каталога.
4. **Типовые страницы:** карточка фильма/сериала с описанием, рейтингом, актёрами, режиссёром, трейлерным блоком, похожим контентом; у сериалов — сезоны и эпизоды.
5. **Личный кабинет:** регистрация, авторизация, проверка полей, роли `user`, `subscriber`, `admin`, избранное, история просмотров и подписка. Кабинет закрыт для неавторизованных посетителей.
6. **Тарифы:** три тарифа с описанием возможностей и демонстрационным оформлением подписки.
7. **GitHub:** инструкция по публикации и проверке изменений через GitHub Desktop — ниже и в `docs/testing.md`.

## Установка через XAMPP
1. Установите XAMPP с PHP 8+ и MySQL/MariaDB.
2. Распакуйте папку `Illuminos` в `C:\xampp\htdocs\`.
3. Запустите в XAMPP модули **Apache** и **MySQL**.
4. Откройте `http://localhost/phpmyadmin/`, выберите импорт и загрузите `database.sql`.
5. Если у MySQL другие реквизиты, измените `$DB_HOST`, `$DB_NAME`, `$DB_USER`, `$DB_PASS` в `config.php`.
6. Перейдите на `http://localhost/Illuminos/`.
7. Для создания администратора один раз откройте `http://localhost/Illuminos/install_admin.php`. Данные демонстрационного входа: `admin@illuminos.local` / `Admin123!`.
8. **Сразу после создания администратора удалите `install_admin.php` с сервера.** Смените демонстрационный пароль.

## Важные ограничения учебной версии
- Страница тарифов сохраняет выбранный план и меняет роль на `subscriber`, но **не списывает реальные деньги**. Для настоящей оплаты нужно подключить платёжного провайдера, настроить договор и API-ключи.
- Трейлер представлен демонстрационным блоком для вставки официального видео. Воспроизведение полного каталога фильмов не реализовано.
- Роль администратора создаётся установочным скриптом; полноценная административная панель управления контентом в эту учебную версию не входит.

## Проверка проекта
Сценарии проверки находятся в `docs/testing.md`. Перед сдачей проверьте сайт локально, сделайте скриншоты основных страниц и убедитесь, что SQL импортирован в phpMyAdmin.

## Публикация в GitHub
```bash
git init
git add .
git commit -m "Initial Illuminos website"
git branch -M main
git remote add origin https://github.com/USERNAME/illuminos.git
git push -u origin main
```
Замените `USERNAME` на свой логин GitHub. Для задания с GitHub Desktop откройте репозиторий в приложении, измените например текст в `README.md`, сохраните файл и убедитесь, что изменение появилось во вкладке Changes. Затем выполните Commit to main и Push origin.

Не публикуйте пароли от базы данных, реальные платёжные ключи и другие секреты.
